# VEX AI — Project Specification

## Phase 1: Local AI chat
- Run a lightweight local chat interface in a browser.
- Use a Node.js/Express backend and Ollama for local model access.
- Keep model integration separate from routes and UI.
- Show loading and useful error messages.
- Do not add persistent memory, voice, PC automation, or cybersecurity execution tools in Phase 1.
- Preserve the repository's original root `README.md`.

## Future roadmap
- Persistent memory with user control.
- Optional voice input/output.
- Carefully permissioned PC automation; ask before destructive, external, or consequential actions.
- Web research with clear source attribution.
- Coding and project-building assistance.
- Ethical cybersecurity learning only in systems the user owns or is explicitly authorized to test. Future tools must not support credential theft, malware, evasion, or attacks on third-party systems.

## Hardware target
Windows 10 Pro, 64-bit, 8 GB RAM, Intel integrated graphics. Prefer lightweight local models and avoid paid API requirements.
